# Invitation typefaces

Self-hosted WOFF2 fonts so the invitation does not depend on Google Fonts at runtime.

- **Lora** — Cyreal; variable regular and italic, weights 400–700. Source: https://github.com/google/fonts/tree/main/ofl/lora
- **Be Vietnam Pro** — Lâm Bảo, Tony Le, ViệtAnh Nguyễn; regular 400 and medium 500. Source: https://github.com/google/fonts/tree/main/ofl/bevietnampro

Original TTF files were converted to WOFF2 without changing glyphs. Lora was subset only to drop its Cyrillic block (Latin, Vietnamese, punctuation, OpenType features and the weight axis are kept as-is). Both families include Vietnamese. Their SIL Open Font License notices are included alongside the font files.
